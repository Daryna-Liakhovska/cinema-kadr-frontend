# Кінотеатр «Кадр»: фронтенд

Простий фронтенд для REST API кінотеатру «Кадр». Сторінка показує афішу фільмів з бекенду: можна шукати фільм за назвою або режисером і фільтрувати за жанром. Написано на HTML, CSS і JavaScript без фреймворків. Дані завантажуються через `fetch` з іншого порту, тому бекенд має бути налаштований на CORS.

Бекенд: https://github.com/Daryna-Liakhovska/cinema-kadr

## Адреси та порти

| Що | Адреса |
|----|--------|
| Фронтенд | http://localhost:3000 |
| Бекенд (API) | http://127.0.0.1:8000/api/v1 |

Адреса API задана у файлі `js/config.js` (`API_BASE_URL`). Бекенд дозволяє запити з `http://localhost:3000` і `http://127.0.0.1:3000`.

## Як запустити проєкт

1. Запустіть бекенд за інструкцією з його README. Він має працювати на `http://127.0.0.1:8000`.
2. Додайте кілька фільмів через Postman-колекцію бекенду або адмінку Django, щоб сторінці було що показати.
3. У папці цього репозиторію запустіть простий вебсервер на порту 3000:

   ```bash
   python3 -m http.server 3000
   ```

4. Відкрийте в браузері http://localhost:3000.

Відкривати `index.html` подвійним кліком не варто: тоді сторінка відкриється з адресою `file://`, а бекенд дозволяє запити лише з `http://localhost:3000`.
